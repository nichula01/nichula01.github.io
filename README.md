# Nichula Wasalathilaka Research Portfolio

This repository is intended to be deployed as a GitHub Pages user site.

- Repository name: `nichula01.github.io`
- Site URL: `https://nichula01.github.io/`
- Main entry file: `index.html` at the repository root
- Images: place static images in `images/`
- CV PDF: place the file at `cv/Nichula_Wasalathilaka_CV.pdf`

## Deploy on GitHub Pages

1. Push this repository to GitHub as `nichula01.github.io`.
2. In GitHub, open `Settings -> Pages`.
3. Set the source to deploy from the default branch root.
4. Confirm that the site loads at `https://nichula01.github.io/`.

## Launch Checklist

- Keep `index.html`, `robots.txt`, `sitemap.xml`, and `.nojekyll` at the repository root.
- Keep asset paths relative, such as `images/...` and `cv/...`.
- Add the CV PDF before launch if you want the public CV link to work immediately.

## Google Indexing

1. Add the deployed site to Google Search Console.
2. Submit `https://nichula01.github.io/sitemap.xml`.
3. Use URL Inspection on `https://nichula01.github.io/` to request indexing after deployment.
